# AI Interaction Summary Logs

This directory contains human-verifiable summaries of AI-assisted development, organized by team member and feature
slice. These are summaries rather than complete chat transcripts.

Each log must include its goal, important prompts, skills used, decisions, corrections, affected components, test
evidence, and commit or PR references. Team members are responsible for checking generated summaries against the
original interaction before submission.

This directory is reserved for AI interaction summaries. Generated GymFlow runtime diagnostics are stored separately
under `data/logs/` and excluded from version control.
