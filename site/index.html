JavaFX desktop application

Run a small gym from one clear workspace.

GymFlow brings members, memberships, finances, attendance, and announcements together in a local-first Owner dashboard.

View releases Read the user guide

Owner workspace

The essentials, without the clutter.

Members

Create searchable profiles, validate Singapore contact details, and securely reset credentials.

Memberships

Record immutable purchases and payments, derive access status, and manage activation.

Finances

Review membership income, add operating expenses, and understand the all-time net position.

Visits

See current visitors and attendance history, with reasoned Owner corrections when needed.

Announcements

Publish gym-wide notices and withdraw them without deleting their history.

Local and private

Keep data in SQLite on the installation, with salted PBKDF2 password hashes and no cloud account.

Installation

Choose the JAR for your computer.

GymFlow targets Java SE 25 and packages JavaFX and SQLite native libraries for Windows x64, Linux x64, macOS x64, and macOS ARM64.

1

Install Java 25.

2

Download the matching JAR from the latest GitHub Release.

3

Run java -jar GymFlow-<platform>.jar.

4

Create the installation's Owner account on first launch.

Testing and operations

Built to be checked.

Automated checks

JUnit and Checkstyle run with ./gradlew clean check.

Platform builds

./gradlew releaseJars verifies all four self-contained distributions.

Monitoring

Rotating local logs capture sanitized failures, while GitHub Actions checks this site every six hours.
